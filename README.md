# 🛡️ ProtectHer: Crime Risk Visualization for Safer Campuses

ProtectHer is a data-driven safety platform that visualizes crime intensity around college zones using geospatial mapping and analytics.

It empowers students—especially women—to make safer, informed decisions about their surroundings.

---

## 📌 Overview

ProtectHer analyzes crime data and transforms it into an interactive map that highlights high-risk and low-risk zones near educational institutions.

The goal is simple:
👉 Increase awareness  
👉 Improve decision-making  
👉 Enhance personal safety  

---

## 🚀 Key Features

- 🗺️ Interactive Crime Intensity Map  
- 📍 Location-based Risk Visualization  
- 🔥 Heatmaps for High-Risk Areas  
- 📊 Data-driven Insights  
- 🧭 Easy Navigation & User-friendly Interface  

---

## 🏗️ System Architecture

The system is built using a geospatial pipeline:

1. **Data Collection**
   - Crime datasets (public/government sources)

2. **Data Processing**
   - Cleaning & preprocessing
   - Risk scoring based on crime frequency

3. **Visualization**
   - Interactive maps using Leaflet
   - Heatmap layers for intensity

---

---

## ⚙️ Core Functionalities

### 🔍 Crime Intensity Mapping
Visualizes crime density using heatmaps to highlight unsafe zones.

### 📍 Location Awareness
Users can view risk levels around specific college areas.

### 📊 Risk Analysis
Assigns safety scores based on:
- Crime frequency  
- Location clustering  
- Severity patterns
